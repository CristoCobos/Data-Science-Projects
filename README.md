### [Apartment Price Prediction](./projects/apartment-price-prediction/)

A machine learning project focused on predicting apartment prices using property characteristics.

The project compares classification and regression approaches, including Decision Trees, Random Forests, and Linear Regression.

**Topics:**
- Classification
- Regression
- Model comparison
- Hyperparameter selection
- Feature importance
- Model evaluation

**Tools:** Python · pandas · NumPy · scikit-learn · Matplotlib · Jupyter Notebook

**Best results:**
- Classification: Random Forest — **90.39% validation accuracy**
- Regression: Decision Tree — **$124,929 validation RMSE**
